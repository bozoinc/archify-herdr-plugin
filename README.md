# archify-map — herdr Plugin

**Published** on herdr marketplace. Install:
```bash
herdr plugin install bozoinc/archify-herdr-plugin
```

## What it does
Shows the archify architecture map in a herdr pane.

## Usage
After install, run the `show-map` action:
- **Title**: Show architecture map
- **Command**: `node entry.js`
